## 7. Exact due/cadence semantics

- Frequencies are fixed elapsed-day labels: daily `1`, weekly `7`, fortnightly `15`, monthly `30`, biannually `182`, annually `365`.
- The sender loops frequencies in that order. For each loop it selects every published alert whose `_candidate_alert_send_email_time` does not exist, OR whose stored date is `<= site-local today minus N days` and whose frequency equals that loop's key.
- An unsent alert is therefore immediately selected in the **first/daily outer loop regardless of its configured frequency**. Once written, it is not normally selected by later loops in the same sequential run.
- State is a date-only `Y-m-d` string built with raw `date()` around `current_time('timestamp')`. Staging reports site timezone `+00:00`; the algorithm mixes WordPress's adjusted timestamp with PHP date formatting instead of explicit `wp_date()`/`wp_timezone()` semantics.
- The next due date is anchored to the date of the last attempt, so late execution drifts cadence. Missed periods coalesce into one attempt; they are not replayed.
- The `WP_Job_Board_Pro_Email::wp_mail()` return is ignored. The sender deletes/re-adds the send date unconditionally after the call, so `false` advances state exactly like success. Empty/broken-result processing also reaches the same write when execution survives warnings.
- Two ordinary sequential invocations on the same day do not resend because today's write is newer than every threshold. Two concurrent workers can both select before either writes and both send. A crash before mail leaves it due; a crash after accepted mail but before the write causes a later duplicate; a fatal before the write likewise leaves it due.
- Lock, claim token, delivery window key, attempt record, retry policy, per-candidate ledger and transport-success state: all absent.

Classification: elapsed-day cadence choice is business-dependent; first-loop frequency bypass, attempt-as-success state, empty/broken advancement, ambiguous timezone handling and lack of concurrency/idempotency are defective; missed-period coalescing is acceptable for a notification product but moot under DROP.
