## Business flow map

### Buy a new employer job package
`Package card → custom JS or native form → Woo cart/session → checkout (guest checkout disabled for job_package) → order pending/on-hold → no entitlement → order processing/completed → order_paid → one job_package entitlement post per quantity → product/order/user/limit/duration meta copied → optional linked pending_payment job approved or left pending due approval setting → quota incremented → employer can submit within remaining limit.`

Current staging nuance: only employer job-package products exist; no published active entitlement currently exists.

### Use an existing package
`Employer submit-job → Paid Listings lists published user package posts → template/UI selects one → validate_package checks ownership + job count/limit → process_package_handler copies duration/urgent/featured meta to job → approve_job_with_package sets publish or pending → package_count increments.`

Custom expiration is **not** part of `package_is_valid`. The UI may hide/disable an “expired” package, but a direct valid POST can still pass if ownership/quota pass.

### Order cancellation/refund
`Order cancelled or fully refunded → order_cancelled → matching published entitlement posts become cancelled → linked jobs for job_package become cancelled → cancellation marker written.`

No role is changed. No handler exists for pending, on-hold or failed. A failed order before payment grants nothing. If an already-processed order later becomes failed, no explicit revocation occurs. Partial refunds may not transition the order to `refunded`, so entitlement revocation is not proven. Resume cancellation references an undefined `$candidate_id`, a vendor edge defect. Re-processing after cancellation cannot reactivate because the processed marker remains.

### RSD bank transfer
`EUR catalog → checkout selects bank_transfer_1 → NBS rate helper/cache → JS displays RSD → create_order mutates items/total/currency to RSD and stores conversion meta → thank-you JS repairs symbols → custom slip + third-party QR rendered.`

The financial source is fragile: HTML parsing plus silent 117.5 fallback; fees/taxes/shipping abstractions are not handled by the custom total recomputation.

### Invoice/company data
`Employer profile → custom lookup/prefill → required checkout company/PIB/MB/address fields → order hooks save address/metadata → admin/PDF/email render data.`

The lookup key mismatch and HPOS legacy writes break confidence in this flow.

### Candidate packages/access
The vendor supports candidate application, CV view, contact view and resume packages, but staging currently has no products/entitlements of these types, candidate applications are free, and candidate views/contact are unrestricted. These paths are dormant infrastructure, not current Raspitajse package policy.
